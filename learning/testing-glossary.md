# Testing Glossary

| Word | Meaning | Example sentence |
|---|---|---|
| Regression testing | Re-testing old features to check a new change didn't break them. | "We ran regression testing after the leave module update." |
| Reproducible | A bug that happens again every time you follow the same steps. | "The crash is reproducible on Android 15 in 3 out of 3 tries." |
| Flaky test | A test that sometimes passes and sometimes fails with no code change. | "This test is flaky; it fails when the page loads slowly." |
| Inconclusive | The result proves nothing either way (your "CANNOT TELL"). | "The run was inconclusive because the emulator froze." |
| Page object | A file that holds one screen's locators and actions, so tests stay clean. | "I added the logout button to the Profile page object." |
