# My English Mistakes

| Wrong | Right | Rule |
|---|---|---|
| i am | I am | "I" is always a capital letter. |
| I am software testing field | I work in the software testing field | A sentence needs a verb (*work*). |
| my english grammer | my English grammar | Languages start with a capital. Spelling: gramm**a**r. |
| that affect me | that affects me | he/she/it/that + verb**s** (present tense). |
| to speed fluently | to speak fluently | *speed* = fast; *speak* = talk. |
| occationaly | occasionally | Spelling: o-c-c-a-s-i-o-n-a-l-l-y. |
| prompt sill | prompt skill | Check typos before sending. |
