# Tester Skills Roadmap

In order. Finish one level before moving deep into the next.

## Level 1: Strong foundations (now)
- [ ] Testing basics and vocabulary: test case, test plan, severity vs priority, bug life cycle (ISTQB Foundation syllabus is a good free guide)
- [ ] JavaScript basics: variables, functions, async/await, arrays, objects
- [ ] Writing clear bug reports: Steps / Actual / Expected with evidence
- [ ] Git basics: commit, branch, diff, log

## Level 2: Automation depth (next 3–6 months)
- [ ] WebdriverIO + Appium: page objects, waits, locators (you already use these)
- [ ] Playwright for web (you already use this): fixtures, assertions, trace viewer
- [ ] API testing: REST, status codes, JSON; tools: Postman, then API tests in code
- [ ] SQL basics: SELECT, WHERE, JOIN, to check data behind the UI

## Level 3: In-demand skills (6–12 months)
- [ ] CI/CD: running tests automatically (GitHub Actions)
- [ ] TypeScript: most new automation projects use it
- [ ] Testing AI features: checking LLM output for wrong facts, unsafe text, format errors (you already do this in FinanceAI)
- [ ] Accessibility testing: screen readers, contrast, labels
- [ ] Performance basics: k6 or similar; security basics: OWASP Top 10

## Optional
- [ ] ISTQB Foundation Level certificate: widely recognised for tester jobs
